# HMC BLE Switch

実機の発車ベルスイッチを ESP32 に接続し、スイッチの状態を BLE で「発車メロディーコレクション」に送るファームウェアです。

## 必要なもの

- ESP32-WROOM-32 搭載の開発ボード
- 無電圧接点のスイッチと配線
- データ通信対応の USB ケーブル
- Arduino IDE と ESP32 ボードパッケージ `esp32 by Espressif Systems`

## 配線

| ESP32 | スイッチ |
| --- | --- |
| GPIO 25 | NO（通常開） |
| GND | COM（共通） |

GPIO 25 の内部プルアップを使用します。接点が閉じるとオンになります。電源付きの実機を使う場合は、ESP32 に電圧が入らないように、電源回路から分離された無電圧接点を使ってください。

## 書き込みと接続

1. リポジトリを `hmc-ble-switch` フォルダにクローンし、Arduino IDE で `hmc-ble-switch.ino` を開きます。
2. ボードマネージャで `esp32 by Espressif Systems` をインストールします。ビルド確認に使ったバージョンは `3.3.12` です。
3. ボードに `ESP32 Dev Module`、ポートに接続した ESP32 を選び、書き込みます。
4. アプリの実機スイッチ設定から BLE 接続を開き、「発車ベルスイッチ」を選択します。

Arduino CLI でのコンパイル

```sh
arduino-cli compile --fqbn esp32:esp32:esp32 .
```

## BLE 仕様

| 項目 | 値 |
| --- | --- |
| サービス UUID | `9460e301-ec3a-4c4a-a1b0-e07c149758ec` |
| 状態特性 UUID | `9460e302-ec3a-4c4a-a1b0-e07c149758ec` |
| 特性の操作 | Read / Notify |
| 値 | 1 バイト、`0x00` がオフ、`0x01` がオン |

状態が 25 ms 安定してから変化を通知します。BLE 接続が切れるとアドバタイズを再開します。
